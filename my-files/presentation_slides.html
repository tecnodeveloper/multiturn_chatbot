Slide 01 — Core Problem 01 / 04

The Challenge: LLMs Are Stateless

Traditional Large Language Model APIs process every prompt independently without memory of past queries.

1

Turn 1: Initial Query

User asks: "Tell me about Shahid Afridi's cricket career."
LLM responds with his stats, records, and accomplishments.

2

Turn 2: Contextual Follow-up

User asks: "How many fours did he hit in ODI cricket?"
Stateless LLM Failure: The model has no memory of "he" referring to Afridi and fails to answer.

Key Limitation: Without a multi-turn memory layer, LLMs cannot sustain continuous, human-like multi-turn conversations.

Slide 02 — Architectural Solution 02 / 04

The Solution: Dynamic Context Persistence

Our application automatically persists session history and reconstructs context dynamically for every turn.

DB

1. Persistent Storage

Every prompt and response is logged in real-time to Supabase Cloud PostgreSQL with session IDs.

CTX

2. Context Assembly

When a new message arrives, the backend fetches the full conversational history from the database.

AI

3. Model Execution

Prepend past dialog history to Meta LLaMA 3 via Groq API for seamless context-aware responses.

Outcome: Complete multi-turn conversational intelligence where the AI effortlessly understands pronouns and historical context.
